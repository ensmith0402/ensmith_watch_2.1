# ⌚ ensmith-watch (Кастомная прошивка для Waveshare ESP32-S3-Touch-AMOLED-2.06)

Кастомная прошивка для умных часов на базе ESP32-S3 (плата Waveshare 2.06"). 
Проект базируется на примере `02_lvgl_demo_v9`, но был значительно переработан и дополнен новым функционалом.

## ✨ Основные возможности

- **Русскоязычный интерфейс**: Полностью переведенный UI.
- **Кастомный циферблат**: 
  - Крупное сегментное время (шрифт DSEG).
  - Сегментная дата и день недели.
  - Иконки статуса Wi-Fi и уровня заряда батареи.
- **Встроенные приложения (в меню)**:
  - **Калькулятор**: базовые арифметические операции с крупным шрифтом.
  - **Таймер**: обратный отсчет с кнопками Пуск/Пауза/Стоп и добавлением времени.
- **Умное энергосбережение**: 
  - Экран гаснет через 60 секунд бездействия.
  - Автоматическое включение экрана при наклоне запястья (акселерометр QMI8658).
  - **Полное выключение питания** по долгому нажатию кнопки PWR (через чип AXP2101).
- **Веб-интерфейс для настройки** (точка доступа `ensmith-watch`):
  - Сканирование доступных Wi-Fi сетей прямо из браузера.
  - Ввод пароля и автоматическая перезагрузка для применения настроек.
  - Настройка яркости и часового пояса.
- **Синхронизация времени**: Автоматическая синхронизация через SNTP при появлении интернета (RTC PCF85063).
- **Диагностика сети**: 
  - Пинг-тест адресов (8.8.8.8 и 1.1.1.1).
  - Спидтест (замер скорости скачивания).
- **Удобное меню (свайп вправо)**:
  - Калькулятор.
  - Таймер.
  - Настройки (яркость, часовой пояс, Wi-Fi, сброс).
  - О часах.
  - Быстрый возврат на главный экран.

## 🛠 Сборка и прошивка

Для сборки требуется **ESP-IDF v5.5** (или новее).

```bash
# 1. Активация окружения
. ~/esp/esp-idf-v5.5/export.sh

# 2. Переход в папку проекта
cd ~/esp/ensmith-watch

# 3. Сборка
idf.py build

# 4. Прошивка (замените порт при необходимости)
idf.py -p /dev/ttyACM0 flash monitor
📶 Первоначальная настройка Wi-Fi
Если часы не могут подключиться к сохраненной сети, они создают точку доступа ensmith-watch.

Подключитесь к ней с телефона или компьютера.

Откройте браузер и перейдите по адресу http://192.168.4.1.

Нажмите «Сканировать», выберите вашу сеть, введите пароль и нажмите «Сохранить». Часы перезагрузятся и подключатся.

📂 Структура проекта
main/watch_ui.c — главный экран (циферблат).

main/calculator_ui.c — калькулятор.

main/timer_ui.c — таймер.

main/power_manager.c — логика сна и пробуждения по наклону.

main/battery_manager.c — работа с батареей и чипом питания AXP2101.

main/web_api.c — веб-сервер для настройки.

main/sntp_manager.c — синхронизация времени.

main/speedtest_ui.c — экраны диагностики сети (пинг и спидтест).

main/settings_ui.c — меню настроек.

Сделано с любовью к ESP32 и LVGL 9.
